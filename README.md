# sing-mcp · 让你的 AI 用自己的声音唱歌

你的 AI 已经有自己的声音了（ElevenLabs、MiniMax、GPT-SoVITS 或别的 TTS）。这个 MCP 让它能**用那个声音翻唱任何一首歌**：你在聊天里丢一个网易云链接，或者说「唱首晴天」，它自己去取歌、换声，一两分钟后交给你一个 mp3。旋律、断句、伴奏全部照原曲，只是唱的人变成了它。

做法分两半：

- **取歌：网易云音乐。** 歌名、链接、分享文字都认；会员歌用你自己的会员账号下载；带时间的歌词一起拿回来（翻唱不改节奏，原曲的歌词时间可以直接用）。
- **换声：「声线」App（荔枝出品）的「唱歌变声」。** 把原曲里的人声换成你克隆好的音色。它没有公开接口，我们用的是**在你自己手机上抓包看到的 App 请求**。

## 你需要

- 一台能跑 Node.js 20 以上的电脑或服务器，装好 **ffmpeg**；
- iPhone 上的 **声线** App，开通会员。积分（2026-11 的价格）：**克隆一个音色 50 积分，翻唱一首 30 积分**，会员每月送积分；
- 你的 AI 已经接好的 TTS 声音（ElevenLabs、MiniMax……都行）。**怎么接 TTS 不在这篇里**，请看你用的那家的教程；
- iPhone 上的抓包工具 **Stream**（免费）；
- 想唱会员歌的话：你自己的网易云会员账号；
- 一个支持 MCP 的客户端：Claude Desktop、Claude Code、Cherry Studio……

## 第一步：在声线里克隆它的声音

声线克隆只要一段清楚的朗读（克隆一次 50 积分）。最好**用你的 AI 自己的 TTS 生成一段**，这样唱出来的就是它平时说话的那个声音：

1. 用它的 TTS（ElevenLabs、MiniMax 或别的）念一段 20～30 秒的日常的话：语速平稳、吐字清楚、没有背景音乐、没有混响。TTS 怎么调用请看各家自己的教程；
2. 把音频传到手机，在声线里「创建角色 / 克隆音色」，上传这段，起个名字（比如它的名字）。

素材越干净，唱出来越像它。

## 第二步：用 Stream 抓一次包

1. 打开 Stream，按它的提示安装并信任证书（「设置 → 通用 → 关于本机 → 证书信任设置」里打开）；
2. 在 Stream 里点「开始抓包」；
3. 切到声线，随便点几下：打开「我的作品」、看一下积分页；
4. 回到 Stream 点「停止」，在「抓包历史」里选刚才那次 → 分享 → **导出 HAR**；
5. 把 .har 文件传到电脑上（微信文件传输助手、AirDrop 都行）。

> 抓到的请求很多是正常的：手机上所有联网的 App 都会被记录。不用挑，整次导出就行。

## 第三步：装好 MCP、生成设置

```bash
git clone <这个仓库> sing-mcp
cd sing-mcp
npm install
npm run config -- 你的抓包.har 你给音色起的名字
```

它会从抓包里取出登录信息，写进 `config.json`，并列出你的音色和剩余积分：

```
你的音色：
  ★ 小机（克隆）
    我自己（克隆）
★ 是翻唱要用的音色。
积分：590
```

**然后把那个 .har 文件删掉。**

想唱网易云会员歌：在浏览器登录 music.163.com，开发者工具 → Application → Cookies 里找到 `MUSIC_U`，填进 `config.json`：

```json
{ "netease": { "musicU": "你的 MUSIC_U" } }
```

不填也能用，只是会员歌下载不到（只能唱免费的歌，或者直接给它一个 mp3）。

## 第四步：接到你的 AI 上

以 Claude Desktop 为例，在 MCP 配置里加：

```json
{
  "mcpServers": {
    "sing": { "command": "node", "args": ["/你的路径/sing-mcp/src/index.js"] }
  }
}
```

Claude Code：`claude mcp add sing -- node /你的路径/sing-mcp/src/index.js`

它会多出三个工具：

| 工具 | 做什么 |
|---|---|
| `cover_song` | 翻唱。`song` 填歌名或网易云链接（网页链接、163cn.tv 短链接、App「分享」出来的整段文字都行），或者 `file` 填本机的音频文件。返回 mp3 的路径和带时间的歌词。 |
| `list_voices` | 列出声线里的音色，★ 是正在用的。 |
| `points` | 还剩多少积分、还能唱几首。 |

然后在聊天里直接说：「唱首《晴天》给我听」，或者把网易云的分享链接丢给它。

## 常见情况

- **「声线的登录过期了」**：重新抓一次包，再跑一遍 `npm run config`。多久过期不一定，正常用 App 的话一般能撑很久。
- **「积分不够了」**：翻唱一首 30 积分，等会员下个月发，或者在 App 里买。
- **「只拿到试听片段 / 下载不到」**：这首要会员，填 `MUSIC_U`，或者直接给它 mp3。
- **超过 5 分钟的歌**：会跳过 30 秒前奏、只唱 5 分钟。
- **咬字有点糊**：直接变声的通病，伴奏越吵越明显。先把人声分离出来再变声也一样，接受就好。
- **没有歌词**：网易云上这首本来就没有歌词。
- **长编号**：声线的音色编号比 JavaScript 能精确表示的数字还长，代码里统一当字符串处理。自己改代码时注意别把它们转成数字。

## 它是怎么工作的

1. 从网易云搜歌或解析链接 → 下载（会员歌用你的 `MUSIC_U`）→ 拿带时间的歌词，去掉作词、作曲、编曲这些制作名单行；
2. 超过 5 分钟就截短 → 转成 m4a；
3. 向声线要一个临时上传凭证，把音频传到它的存储（标准的 S3 上传，用临时凭证签名，不涉及任何破解）；
4. 提交「唱歌变声」任务，选你的音色；
5. 每隔几秒查一次作品列表，好了就下载成品，存到 `out/`。

全部代码在 `src/`：`netease.js` 取歌，`shengxian.js` 声线，`cover.js` 串起来，`index.js` 是 MCP。
